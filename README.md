# 期中複習競賽（Kahoot 式四選一）

中興大學 生物產業管理研究所（生管學程）1151 學期「量化研究法（上）」期中考複習的課堂網站，授課教師：王思永。

全班用手機掃 QR、免登入、輸入一個 ID 進場。老師按「開始競賽」後，每題四選一（A/B/C/D）即時作答；投影幕同一畫面看到已回答人數，按「結束作答」公佈 A/B/C/D 分佈、正解與解析，再按「下一題」。全部答完後看成績：學生看自己的分數與全班分佈，投影看全班平均、答對題數分佈與「錯最多的題目」，點任一題可回看加強複習。

線上網址：https://halcyone1234-ux.github.io/midterm-quiz/

## 畫面

| 網址 | 給誰 | 內容 |
|---|---|---|
| `/` 或 `/#join` | 學生 | 進場（輸入 ID）→ 等待 → 作答 → 看對錯與解析 → 最後看自己的分數、全班分佈、要加強的題目 |
| `/#board` | 投影 | 大廳 QR 與進場人數 → 題目與四色答案磚、已回答人數與進度條 → 分佈與正解 → 成績頁。老師在同一瀏覽器登入過控制台時，投影畫面下方直接出現控制按鈕 |
| `/#admin` | 老師 | 控制台（PIN）：開始／結束作答／下一題／看成績／回看／再比一次；題庫編輯；學生成績表與 Excel 下載；清空 |

網址加 `?c=代碼`（例如 `?c=1152-midterm`）可開一個全新的班級資料。加 `?mock=1` 強制用本機測試模式試跑流程（資料只存在這台瀏覽器）。

## 題庫

預設題庫為「量化研究法（上）期中考複習卷」25 題（含解析），寫在 `questions.js`。老師在控制台「編輯」可用純文字改題，格式與複習卷排版一致，可直接從 Word 貼上：

```
# 標題（可省略）
[W01｜內生性四張臉]
1. 題目文字
(A) 選項
(B) 選項
(C) 選項
(D) 選項
答：C
解：解析（可省略）
```

套用後題庫存進資料庫，蓋過預設；「載回預設 25 題」會清掉自訂題庫。

分數以百分制計算（答對題數 ÷ 總題數 × 100；25 題時每題 4 分，與期中考相同）。

## 課堂操作 SOP

1. 課前：投影畫面開 `/#board`；老師在同一台電腦另開 `/#admin` 輸入 PIN（之後投影畫面下方會出現控制按鈕）。需要時先「清空」上次的資料。
2. 學生掃 QR 進場、輸入 ID。投影大廳顯示人數與名單。
3. 按「開始競賽」。學生手機出現第 1 題；投影顯示題目、四色磚、已回答人數。
4. 人數差不多了按「結束作答，公佈答案」：投影顯示各選項人數與百分比、正解打亮、解析；學生看到自己對錯。
5. 「下一題」繼續；最後一題揭曉後按「看成績」。
6. 成績頁：投影看全班平均與分佈、「錯最多的題目」；點錯最多的題目回看統計與解析，講完按「回成績頁」。學生手機看自己的分數、贏過多少比例同學、要加強的題目清單。
7. 控制台可下載 Excel（成績：每人每題作答；題目：各題答對率與選項分佈）。「再比一次」用同一份題庫開新的一局，舊紀錄保留在資料庫。

## 安裝

本站沿用星座問卷工作坊的 Firebase 專案（`zodiac-af366`），資料放在 `quiz/<班級代碼>` 之下，與星座問卷的 `classes/` 互不干擾。只需一個步驟：

1. Firebase 主控台 → Realtime Database → 「規則」分頁，把本 repo 的 `database.rules.json` 整份貼上（它包含星座問卷原本的規則加上 `quiz` 的規則），發布。

若要改用別的 Firebase 專案，把 `firebase-config.js` 裡的 `firebase` 設定換掉即可；`apiKey` 是 `YOUR_…` 時自動走本機測試模式。

## 技術

- 純靜態：`index.html`、`style.css`（沿用星座問卷）、`quiz.css`、`questions.js`（預設題庫）、`data.js`（Firebase／mock 資料層、題庫文字格式）、`app.js`（路由與畫面），無建置步驟。
- CDN：Firebase JS SDK 10.12（compat）、SheetJS 0.18.5、qrcodejs 1.0.0。
- 資料結構：`game`（status、index、run）、`bank`（題庫）、`players/<裝置碼>`（ID）、`answers/<局>/<題>/<裝置碼>`（choice）。成績全由 answers 與題庫在前端算出，不另存。
- 身分：每支手機自動產生匿名碼存在 localStorage，進場時輸入 ID。每題每人只能寫一次（規則 `!data.exists()`），答了就鎖。
- 規則開放讀取（題庫含正解也讀得到，預設題庫本來就在公開的 `questions.js`），控制台 PIN 只在前端把關，適合課堂複習用途。
